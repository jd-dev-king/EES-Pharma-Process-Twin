# Sprint 3.0.3 — Process Overview Digital Twin

Adds a modular, animated Process Overview mission-control dashboard. It preserves all validated business logic and uses existing application state only.

## Highlights
- Executive KPI ribbon
- Interactive plant process flow
- Animated tanker, tank, packaging conveyor, and shipping dock scenes
- Active batch lanes
- Live asset telemetry
- Clickable digital-thread events
- Mini PLC network status
- Reduced-motion accessibility support
