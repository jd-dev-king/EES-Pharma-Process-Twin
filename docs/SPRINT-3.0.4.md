# Sprint 3.0.4 — Immersive 3D Plant Navigation

Adds an isolated, read-only isometric 3D digital-twin module without changing validated execution logic.

## Included
- Interactive plant floor covering Office, Warehouse, Weighing, Bulk, Mixing, QA, R&D, Packaging, Shipping, Reliability, Compliance, and Automation.
- Live room-state coloring from existing equipment data.
- Camera presets for overview, production, warehouse, laboratories, and shipping.
- Animated tanks, conveyors, forklift, tanker/material routes, shipping truck, and PLC rack.
- Zone faceplate with live assets, levels, PO context, and direct department/PLC navigation.
- Motion pause, label toggle, responsive layout, and reduced-motion support.
- Existing 2D Process Overview remains available as the primary fallback.

No database changes are required.
