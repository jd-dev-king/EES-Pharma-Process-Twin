# EES Frontend

React/Vite zoned operations shell for the Enterprise Execution Suite.

Sprint 2.1.3 activates the Premix & Mixing White Zone with two mix-room work centers, live batch telemetry, automatic sequence ticks, premix interlocks, PLC fault recovery, hold-tank selection, and Office route-change approvals.

```bash
npm install
npm test -- --run
npm run build
npm run dev
```
